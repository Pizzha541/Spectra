SPECTRA incorpora actualizaciones firmadas para Windows x64. La aplicación comprueba GitHub Releases al abrirse y cada cuatro horas. En Configuración puedes buscar versiones e incluir preliminares.

Cuando haya una versión nueva, podrás leer los cambios, descargarla mientras trabajas y elegir cuándo instalar y reiniciar. Para pasar desde la versión 0.1.0, ejecuta el instalador de esta release una vez.
